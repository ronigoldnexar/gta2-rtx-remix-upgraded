The browser gets the picture and the game's sound and sends your keys and mouse. The sound starts with Play (top right: mute and volume, and the sound's delay in ms). If the view feels sluggish, lower the quality slider in the noVNC side panel. Click inside the game first so keys go to it. Mouse look is off over this connection by default (a remote pointer jumps); start with PLAY_MOUSE=1 to use it.
